# VesMod

VesMod is a Python package for extracting membrane contours from microscopy videos of giant unilamellar vesicles (GUVs) and estimating membrane bending rigidity from thermal shape fluctuations.

The package consists of two primary components:

* **VesEdge** – Automated vesicle contour detection from microscopy images and videos.
* **EdgeMod** – Analysis of vesicle contour fluctuations to estimate membrane bending modulus ($k_C$) and membrane tension ($\sigma$).

VesMod was developed to provide a reproducible workflow for transforming raw microscopy data into quantitative measurements of membrane mechanical properties.

---

## Features

### VesEdge

* Automated vesicle edge detection from microscopy images
* Robust contour extraction in the presence of imaging artifacts
* Processing of ND2 microscopy videos
* Export of detected contours as NumPy arrays
* Generation of annotated GIFs for quality control

### EdgeMod

* Fourier analysis of vesicle contour fluctuations
* Extraction of membrane bending modulus ($k_C$)
* Optional fitting of membrane tension ($\sigma$)
* JSON export of analysis results
* Batch processing of multiple contour files

## Installation

Clone the repository:

```bash
git clone https://github.com/BranniganLab/VesMod.git
cd VesMod
```

Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

Install the package:

```bash
pip install .
```

## Quick Start

### Extract vesicle contours

```bash
vesedge data/nd2/ \
    --micron-to-pixel-ratio 0.0744
```

For each video, VesEdge generates:

* Contour coordinates (`.npy`)
* Annotated GIF visualizations (`.gif`)

### Calculate bending moduli

Analyze contour files generated by VesEdge:

```bash
edgemod contours/ \
    --lower-fitting-bound 3 \
    --upper-fitting-bound 8 \
    --lmax 500 \
    --free-sigma
```

For each contour file, EdgeMod reports:

* Membrane bending modulus ($k_C$)
* Membrane tension ($\sigma$) (optional)

Results are written to JSON files for downstream analysis.
